# Математические методы и формулы расчёта

Документ описывает методы, реализованные в программе, с названиями согласно
русскоязычной литературе. Формулы соответствуют коду один в один; в конце
каждого раздела указан файл реализации.

---

## Краткая сводка одним абзацем

В основе лежит **метод разделения переменных (метод Фурье)**: для пустого
прямоугольного волновода собственные волны типов **H (TE)** и **E (TM)**
получаются с поперечными волновыми числами k_x = mπ/a, k_y = nπ/b,
k_c² = k_x² + k_y², комплексной постоянной распространения
γ = √(k_c² − ω²με_c) = α + jβ и критической частотой
f_c = c·k_c/(2π√(ε_r·μ_r)), где ε_c = ε₀ε_r − jσ/ω, а амплитуда нормируется
условием ½∬Re(E×H\*)·ẑ dA = P₀ = 1 Вт, вычисляемым **квадратурой средних
прямоугольников**; сплошная поперечная пластина сводится к короткому замыканию
из условия n̂×E = 0, что даёт S₁₁ = −e^(−2γd). Неоднородности (диафрагмы,
штыри, щель, ступенчатый профиль) считаются **методом конечных элементов в
частотной области**, слабая форма строится **методом Галёркина**, дискретизация
ведётся **рёберными элементами Неделека** в пространстве **H(rot)** на
тетраэдрах с условием идеального проводника на металле, **поглощающими
граничными условиями первого порядка** на портах и **идеально согласованным
поглощающим слоем (PML)**, а разреженная СЛАУ решается **обобщённым методом
минимальных невязок (GMRES)** с предобуславливателем по **методу
Гаусса–Зейделя**; диафрагмы с прямоугольным окном рассчитываются точнее и
быстрее **методом частичных областей (методом сшивания по модам)**. Омические потери вводятся **методом возмущений** через
поверхностное сопротивление R_s, эквивалентное **импедансному граничному
условию Леонтовича**, а силовые линии интегрируются **методом Рунге–Кутты
четвёртого порядка**.

## 1. Постановка задачи и обозначения

Ось z направлена вдоль волновода, начало координат — в центре полости.
Внутренние размеры получаются из внешних вычитанием двух толщин стенки:

$$a = W - 2t_w, \qquad b = H - 2t_w$$

Все поля — комплексные амплитуды (фазоры) с временной зависимостью
$e^{+j\omega t}$; мгновенное значение восстанавливается как

$$\mathbf{F}(\mathbf{r},t) = \mathrm{Re}\left[\mathbf{F}(\mathbf{r})\,e^{\,j\omega t}\right], \qquad \omega = 2\pi f$$

Заполнение — пассивная среда с комплексной диэлектрической проницаемостью:

$$\varepsilon_c = \varepsilon_0\varepsilon_r - j\frac{\sigma}{\omega}, \qquad \mu = \mu_0\mu_r$$

## 2. Метод разделения переменных (метод Фурье)

Регулярный волновод рассчитывается аналитически. Поперечные волновые числа,
критическое волновое число и критическая частота:

$$k_x = \frac{m\pi}{a}, \qquad k_y = \frac{n\pi}{b}, \qquad k_c^2 = k_x^2 + k_y^2, \qquad f_c = \frac{c\,k_c}{2\pi\sqrt{\varepsilon_r\mu_r}}$$

Постоянная распространения берётся как пассивная ветвь квадратного корня
(Re γ ≥ 0):

$$\gamma = \sqrt{k_c^2 - \omega^2\mu\,\varepsilon_c} = \alpha + j\beta, \qquad \lambda_в = \frac{2\pi}{\beta}$$

Продольный множитель для суперпозиции падающей (A) и отражённой (B) волн:

$$f(\tilde z) = A\,e^{-\gamma\tilde z} + B\,e^{+\gamma\tilde z}, \qquad f'(\tilde z) = \gamma\left(B\,e^{+\gamma\tilde z} - A\,e^{-\gamma\tilde z}\right)$$

**Волны типа H (TE):** с потенциалом ψ = cos(k_x x̃)·cos(k_y ỹ)

$$H_z = f\,\psi, \qquad \mathbf{H}_t = \frac{f'}{k_c^2}\nabla_t\psi, \qquad E_x = -\frac{j\omega\mu}{k_c^2}f\frac{\partial\psi}{\partial\tilde y}, \qquad E_y = +\frac{j\omega\mu}{k_c^2}f\frac{\partial\psi}{\partial\tilde x}$$

**Волны типа E (TM):** с потенциалом φ = sin(k_x x̃)·sin(k_y ỹ)

$$E_z = f\,\varphi, \qquad \mathbf{E}_t = \frac{f'}{k_c^2}\nabla_t\varphi, \qquad H_x = +\frac{j\omega\varepsilon_c}{k_c^2}f\frac{\partial\varphi}{\partial\tilde y}, \qquad H_y = -\frac{j\omega\varepsilon_c}{k_c^2}f\frac{\partial\varphi}{\partial\tilde x}$$

**Нормировка по мощности.** Средний по времени вектор Пойнтинга и мощность
через сечение (интеграл берётся **квадратурой средних прямоугольников** на
сетке 80×56):

$$\bar{\mathbf{S}} = \frac{1}{2}\mathrm{Re}\left(\mathbf{E}\times\mathbf{H}^{*}\right), \qquad P(z) = \iint \bar S_z\,dx\,dy = P_0 = 1\ \text{Вт}$$

*Реализация:* `em/analytic_waveguide_solver.cpp`, `em/rectangular_mode_field.cpp`

### 2.1. Круглое сечение — функции Бесселя

Для волновода круглого сечения радиуса $a$ разделение переменных в
цилиндрических координатах $(r,\varphi,z)$ даёт вместо синусов и косинусов
функции Бесселя первого рода $J_m$. Критическое волновое число задаётся нулями
$J_m$ и её производной:

$$k_c^{\text{TE}} = \frac{p'_{mn}}{a}, \qquad k_c^{\text{TM}} = \frac{p_{mn}}{a}$$

где $p_{mn}$ — n-й положительный нуль $J_m$, а $p'_{mn}$ — n-й положительный
нуль $J'_m$. Азимутальный индекс $m \ge 0$, радиальный $n \ge 1$. Низшая мода
круглого волновода — **TE₁₁** с $p'_{11} = 1{,}8412$ (у прямоугольного низшая
TE₁₀), следующая — TM₀₁ с $p_{01} = 2{,}4048$.

Продольная функция и поперечные компоненты строятся по той же схеме, что и в
декартовом случае, с заменой $\partial/\partial x \to \partial/\partial r$ и
$\partial/\partial y \to (1/r)\,\partial/\partial\varphi$:

$$\psi = J_m(k_c r)\cos(m\varphi), \qquad
E_r = -\frac{j\omega\mu}{k_c^2}f\,\frac{1}{r}\frac{\partial\psi}{\partial\varphi}, \qquad
E_\varphi = +\frac{j\omega\mu}{k_c^2}f\,\frac{\partial\psi}{\partial r}$$

Нули ищутся численно — сканированием с постоянным шагом и последующей
дихотомией: при малых $m$ и $n$ это дешевле и надёжнее асимптотики Мак-Магона,
которая на первых нулях низких порядков может сойтись к соседнему корню.
Интеграл мощности по сечению берётся в полярных координатах с весом
$r\,dr\,d\varphi$ на сетке 64×128.

Моды с $m \ge 1$ вырождены: паре отвечают две поляризации, $\cos(m\varphi)$ и
$\sin(m\varphi)$, повёрнутые друг относительно друга на $90^\circ/m$. Решатель
считает одну поляризацию из пары.

*Реализация:* `em/circular_mode_field.cpp`, `em/cylindrical_bessel.cpp`

## 3. Короткое замыкание — сплошная поперечная пластина

На идеально проводящей грани касательное электрическое поле обращается в ноль.
Для волн типа H E_t ∝ f, для волн типа E E_t ∝ f′, поэтому знаки отражения
продольной амплитуды различны:

$$\text{H (TE)}:\ f(d) = 0 \Rightarrow B = -A\,e^{-2\gamma d}, \qquad \text{E (TM)}:\ f'(d) = 0 \Rightarrow B = +A\,e^{-2\gamma d}$$

В конвенции поперечного электрического поля коэффициент отражения на входном
порту одинаков для обоих семейств:

$$S_{11} = -e^{-2\gamma d}, \qquad S_{21} = S_{12} = 0$$

где d — расстояние от плоскости порта до передней грани пластины.

*Реализация:* `em/transverse_pec_partition_solver.cpp`

## 4. Метод частичных областей (метод сшивания по модам)

Применяется для поперечной пластины конечной толщины t с **прямоугольным
окном** (индуктивные, ёмкостные и резонансные диафрагмы). Структура делится на
три частичные области: волновод A (сечение a×b) при z < z₁, «малый» волновод B
с сечением окна w×h при z₁ < z < z₂ = z₁ + t и снова волновод A при z > z₂.
В каждой области поперечное поле разлагается по полной ортонормированной
системе собственных волн:

$$\mathbf{E}_t^{A} = \sum_m (a_m e^{-\gamma_m (z-z_1)} + b_m e^{+\gamma_m (z-z_1)})\,\mathbf{e}_m, \qquad \mathbf{H}_t^{A} = \sum_m Y_m (a_m e^{-\gamma_m(z-z_1)} - b_m e^{+\gamma_m(z-z_1)})\,(\hat{\mathbf{z}}\times\mathbf{e}_m)$$

с модовыми проводимостями Y_m = γ_m/(jωμ) для волн H и Y_m = jωε_c/γ_m для
волн E. На плоскостях z₁ и z₂ сшиваются касательные поля: E_t непрерывно на
всём сечении (и равно нулю на металле), H_t непрерывно на окне. Проекция этих
условий на модовые базисы даёт интегралы связи

$$X_{mn} = \iint_{\text{окно}} \mathbf{e}_m^{A}\cdot\mathbf{e}_n^{B}\,dA$$

(вычисляются в замкнутом виде через произведения синусов и косинусов) и
блочную систему сшивания относительно амплитуд окна c, d:

$$(G + Y_B)\,c + (G - Y_B)P\,d = 2X^{T}Y_A\,a, \qquad (G - Y_B)P\,c + (G + Y_B)\,d = 0$$

где G = XᵀY_A X — матрица проводимости стыка, P = diag(e^{−γₙt}) — пролёт
через толщину пластины (отражённые амплитуды отнесены к z₂, растущих экспонент
нет). Отражённые и прошедшие амплитуды: b = X(c + Pd) − a, f = X(Pc + d).
Число мод областей связано условием **относительной сходимости**
N_A/N_B ≈ a/w (иначе неверно передаётся поведение поля у кромки).

Свойства реализации, подтверждённые тестами: баланс мощности
|S₁₁|² + |S₂₁|² = 1 выполняется с машинной точностью (~10⁻¹⁶), взаимность
S₁₂ = S₂₁ — структурно; сходимость по числу мод — изменение |S₁₁| на 0.002
при переходе 8×8 → 12×12; тонкое индуктивное окно d = a/2 согласуется с
формулой Марковица B/Y₀ = (λ_в/a)·ctg²(πd/2a) в пределах 5% (точность самой
формулы); МКЭ при измельчении сетки сходится к результату метода
(0.860 → 0.814 → предел ≈ 0.77 при значении метода 0.771).

*Реализация:* `em/mode_matching_iris_solver.cpp`

## 5. Метод конечных элементов в частотной области

Применяется для круглых отверстий, язычков, штырей, щели и ступенчатого
профиля — всего, что не сводится к прямоугольным частичным областям. Решается
векторное волновое уравнение:

$$\nabla\times\left(\mu^{-1}\nabla\times\mathbf{E}\right) - \omega^2\varepsilon_c\,\mathbf{E} = 0$$

### 5.1. Слабая формулировка (метод Галёркина)

$$\left(\mu^{-1}\nabla\times\mathbf{E},\,\nabla\times\mathbf{v}\right) - \omega^2\left(\varepsilon_c\mathbf{E},\,\mathbf{v}\right) + \frac{j\beta}{\mu}\left\langle\mathbf{E}_\tau,\mathbf{v}_\tau\right\rangle_{\Gamma_1\cup\Gamma_2} = \frac{2j\beta}{\mu}\left\langle\mathbf{E}^{пад},\mathbf{v}\right\rangle_{\Gamma_1}$$

Первые два слагаемых дают жёсткостную и массовую матрицы, третье —
**поглощающее граничное условие первого порядка** на портах Γ₁ и Γ₂, правая
часть — возбуждение падающей модой. Фазовая постоянная порта:

$$\beta = \sqrt{k_0^2\,\mathrm{Re}(\varepsilon_r\mu_r) - k_c^2}, \qquad k_0 = \omega/c$$

### 5.2. Дискретизация — рёберные элементы Неделека

Пространство **H(rot)**, согласованные по касательной рёберные (векторные)
элементы на тетраэдрах. На металле — **граничное условие идеального
проводника**:

$$\hat{\mathbf{n}}\times\mathbf{E} = 0$$

Магнитное поле восстанавливается из решения:

$$\mathbf{H} = \frac{j}{\omega\mu}\nabla\times\mathbf{E}$$

Автоматический шаг сетки (k — множитель качества расчёта):

$$h = k\cdot\min\left(\frac{a}{8},\ \frac{b}{5},\ \frac{\lambda_m}{12}\right), \qquad \lambda_m = \frac{c}{f\sqrt{\max(1,|\varepsilon_r\mu_r|)}}$$

### 5.3. Идеально согласованный поглощающий слой (PML)

Комплексное растяжение координат с полиномиальным профилем степени p − 1:

$$s(d) = 1 - j\,\frac{p\,\sigma_0}{k\,T^{p}}\,d^{\,p-1}, \qquad \sigma_0 = -\frac{1}{2}\ln R, \qquad 0 \leq d \leq T$$

Материальные тензоры анизотропного слоя:

$$\Lambda = \mathrm{diag}\left(\frac{s_y s_z}{s_x},\ \frac{s_x s_z}{s_y},\ \frac{s_x s_y}{s_z}\right), \qquad \tilde\mu = \mu\Lambda, \qquad \tilde\varepsilon = \varepsilon_c\Lambda$$

Знак мнимой части отрицателен: для конвенции e^{+jωt} это обеспечивает
затухание уходящей волны.

### 5.4. Решение СЛАУ — обобщённый метод минимальных невязок (GMRES)

Комплексная система A·x = b собирается в блочной форме по вещественной и
мнимой частям; GMRES минимизирует невязку на подпространстве Крылова:

$$\min_{x\,\in\,x_0 + \mathcal{K}_m(A, r_0)}\left\|b - A x\right\|_2, \qquad \mathcal{K}_m = \mathrm{span}\{r_0, Ar_0, \ldots, A^{m-1}r_0\}$$

Предобуславливатель — один проход **метода Гаусса–Зейделя** по вещественной
положительно определённой форме. Критерий приёмки — явная относительная
невязка:

$$r = \frac{\left\|b - A x\right\|_2}{\left\|b\right\|_2} \leq 10^{-3}$$

### 5.5. Извлечение S-параметров

Амплитуда моды находится проекцией поля на модовый профиль порта:

$$p(z) = \frac{\sum \mathbf{E}(x,y,z)\cdot\mathbf{e}_{ref}^{*}(x,y)}{\sum\left|\mathbf{e}_{ref}(x,y)\right|^{2}}$$

$$S_{11} = \left(p(z_1{+}\delta) - e^{-j\beta\delta}\right)e^{-j\beta\delta}, \qquad S_{21} = p(z_2{-}\delta)\,e^{+j\beta(L-\delta)}$$

*Реализация:* `em/mfem_frequency_domain_backend.cpp`, `em/gmsh_tetrahedral_mesher.cpp`

## 6. Потери в стенках — метод возмущений

Поверхностное сопротивление металла (эквивалент **импедансного граничного
условия Леонтовича**):

$$R_s = \sqrt{\frac{\omega\mu}{2\sigma}}$$

Мощность потерь на единицу длины и проводниковое затухание:

$$P_{ст} = \frac{R_s}{2}\oint\left|\mathbf{H}_\tau\right|^2 dl, \qquad \alpha_c = \frac{P_{ст}}{2P_0}$$

Полное затухание α = α_д + α_c входит в γ, поэтому автоматически уточняются
|S₂₁| = e^(−αL) и рассеиваемая мощность. Контрольное сравнение — замкнутая
формула для волны H₁₀:

$$\alpha_c = \frac{R_s}{b\,\eta\sqrt{1 - (f_c/f)^2}}\left[1 + \frac{2b}{a}\left(\frac{f_c}{f}\right)^2\right]$$

*Реализация:* `em/analytic_waveguide_solver.cpp`

## 7. Запасённая энергия и добротность

Средние по времени запасённые энергии на единицу длины и добротность,
ограниченная суммарными потерями:

$$w_e = \frac{\mathrm{Re}\,\varepsilon_c}{4}\iint\left|\mathbf{E}\right|^2 dA, \qquad w_m = \frac{\mu}{4}\iint\left|\mathbf{H}\right|^2 dA$$

$$Q = \frac{\omega\left(w_e + w_m\right)}{P_{пот}} = \frac{\omega\left(w_e + w_m\right)}{2\alpha P_0}$$

## 8. Производные величины и построение линий поля

Поверхностный ток и средний поток мощности:

$$\mathbf{J}_s = \hat{\mathbf{n}}\times\mathbf{H}, \qquad \bar{\mathbf{S}} = \frac{1}{2}\mathrm{Re}\left(\mathbf{E}\times\mathbf{H}^{*}\right)$$

Силовые линии интегрируются **методом Рунге–Кутты четвёртого порядка** по
нормированному полю направлений:

$$\mathbf{r}_{n+1} = \mathbf{r}_n + \frac{h}{6}\left(\mathbf{k}_1 + 2\mathbf{k}_2 + 2\mathbf{k}_3 + \mathbf{k}_4\right)$$

Расстановка стрелок волны H₁₀ — равнопоточная, плотность повторяет
распределение |sin(πx̃/a)|:

$$q_k = \frac{k + 1/2}{N}, \qquad \theta_k = \arccos(1 - 2q_k), \qquad x_k = a\left(\frac{\theta_k}{\pi} - \frac{1}{2}\right)$$

Оценка возбуждения щели (инженерная, первого порядка):

$$k_{щ} = \frac{\left|\mathbf{J}_s(\mathbf{r}_c)\cdot\hat{\mathbf{w}}\right|}{\max\left|\mathbf{J}_s\right|}\cdot\left|\mathrm{sinc}\!\left(\frac{\beta\,l_{щ}}{2}\right)\right|$$

*Реализация:* `postprocessing/field_visualization_generator.cpp`,
`postprocessing/slot_excitation_estimator.cpp`

## Сводка методов

| Задача | Метод |
|---|---|
| Собственные волны регулярного волновода | Метод разделения переменных (метод Фурье) |
| Круглое сечение | Разделение переменных в цилиндрических координатах, функции Бесселя |
| Классификация волн | Волны типа H (TE) и типа E (TM) |
| Нормировка мощности, интегралы | Квадратура средних прямоугольников |
| Сплошная поперечная пластина | Короткое замыкание, граничное условие n̂×E = 0 |
| Диафрагмы, штыри, щель, профиль | Метод конечных элементов в частотной области |
| Слабая формулировка | Метод Галёркина |
| Дискретизация | Рёберные элементы Неделека, пространство H(rot) |
| Границы: металл | Условие идеального проводника |
| Границы: порты | Поглощающее условие первого порядка |
| Границы: излучение щели | Идеально согласованный поглощающий слой (PML) |
| Решение СЛАУ | Обобщённый метод минимальных невязок (GMRES) |
| Предобуславливание | Метод Гаусса–Зейделя |
| Потери в стенках | Метод возмущений, условие Леонтовича |
| Силовые линии | Метод Рунге–Кутты 4-го порядка |

| Прямоугольные диафрагмы (ирисы) | Метод частичных областей (метод сшивания по модам) |

Диафрагмы с прямоугольным окном рассчитываются **методом частичных областей**
точно (полуаналитически); круглые отверстия, язычки и щели — методом конечных
элементов.
